# R6 Data Directory

This directory documents the expected dataset organisation.

## Raw datasets

- raw/mirror/ : Mirror dataset source files
- raw/YawDD/ : YawDD source files
- raw/UTA_RLDD/ : RLDD source files, if obtained
- raw/DMD/drowsiness/ : DMD drowsiness material, if obtained
- raw/DMD/distraction/ : DMD distraction material, if obtained

## Processed datasets

- processed/mirror_sqpnp_full/
- processed/yawdd_r6/
- processed/processed_rldd/
- processed/r6_dataset_audit/

Place locally processed data in the appropriate directories.

Do not upload original videos, large feature arrays, or restricted dataset
material to this repository. Follow each dataset's licence and access terms.
